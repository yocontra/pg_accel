## Bucket definitions

- **A. Working**: speedup ≥ 1.10x at ≥ 2 scales, p < 0.01, Cohen's d > 0.8
- **B. Not dispatching**: |speedup − 1.0| < 0.02 and `gpu_kernel_executions` delta = 0 during the run
- **C. Dispatching but slow**: speedup ∈ [0.85, 1.05], `gpu_kernel_executions > 0`, `cpu_fallback_count == 0`
- **D. Regression**: speedup < 0.90 at any scale with p < 0.05
